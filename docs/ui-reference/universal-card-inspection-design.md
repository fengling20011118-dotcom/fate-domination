# Fate/Domination 全桌卡牌双层检视设计

## 目标

桌面端所有可见卡牌使用统一检视模型，使玩家无需辨认缩略图小字即可快速理解卡牌，同时严格区分“查看权限”与“操作权限”。移动端未来复用完整检视层。

## 交互层级

### 悬停速览

- 桌面端鼠标悬停卡牌后显示固定位置的快速预览，不持续追随鼠标。
- 面板宽约 360–400px，包含放大卡图、中文规则复述、费用、威力、来源、公开状态。
- 面板根据卡牌位置选择左右侧，并限制在视口范围内。
- 离开卡牌与面板后关闭；键盘聚焦产生相同效果。

### 点击完整检视

- 单击任意可见卡牌后，在屏幕中央打开模态检视层。
- 左侧显示完整大卡图，右侧展示名称、类型、所有者、费用、威力、阶段、公开范围、关键词和完整中文说明。
- 点击遮罩空白处、关闭按钮或按 `Esc` 退出。
- 完整检视层负责承载可执行动作，悬停层只提供信息。

## 查看与操作权限

| 状态 | 自己区域内的卡牌 | 其他玩家或公共卡牌 |
|---|---|---|
| 自己的行动回合 | 查看；后端返回合法动作时可操作 | 仅查看 |
| 自己的其他阶段 | 查看；仅显示当前阶段合法动作 | 仅查看 |
| 非本人回合 | 仅查看；响应窗口开放时可显示响应动作 | 仅查看 |
| 房主代理 | 使用被代理玩家的权限 | 仅查看 |

前端不推断合法性。操作按钮完全来自后端 `availableActions`，例如 `ADD_REGULAR_PLAY`、`ADD_ADDITIONAL_PLAY`、`ACTIVATE`、`REVEAL`、`REMOVE_FROM_PLAY`。

## 适用卡牌

- 自己的御主卡、从者卡、技能牌与手牌。
- 事件牌与局势牌。
- 放置在地点上的持续效果牌。
- 各玩家已经公开或使用过的技能牌、攻击牌和其他公共牌。
- 其他规则允许当前观察者查看的卡牌。

暗置牌只显示统一牌背、归属和允许公开的信息，不泄露名称、卡图或说明。

## 中文规则复述数据

中文复述是经过人工确认的卡牌静态数据，不在悬停时调用大语言模型生成。建议卡牌视图模型包含：

- `name`
- `imageUrl`
- `cardType`
- `ownerLabel`
- `cost`
- `power`
- `allowedPhases`
- `visibility`
- `keywords`
- `originalText`
- `rulesSummaryZh`
- `availableActions`

若缺少结构化复述，界面明确显示“规则说明待录入”，并可进入房主裁定流程，不由客户端临时解释规则。

## 原型验收

- 1440×900 下悬停层和居中层不超出视口。
- 所有演示卡牌均可悬停速览及点击完整检视。
- 至少展示事件牌、局势牌、地点效果牌和其他玩家公开技能牌入口。
- 点击自己的技能牌可在完整检视层加入或移出出牌区。
- 点击公共牌或非本人牌时不显示操作按钮。
- 支持键盘聚焦、`Esc` 关闭和遮罩关闭。
- 页面无横纵向溢出、无缺失素材、无 JavaScript 错误。
