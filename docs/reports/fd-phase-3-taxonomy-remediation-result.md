## RESOURCE_NUMERIC_CORE Decision

Decision: `RESOURCE_NUMERIC_CORE_DIRECT_ACTION` should be the first implementation factory slice candidate if runtime work resumes.

Rationale:

- It can establish a typed direct resource primitive contract quickly.
- It can require compiler fail-closed behavior without solving Trigger/Lifecycle/Interaction runtime first.
- It already has implementation-candidate evidence and direct consumer burn-down facts.
- It can reduce direct legacy `resolveEffect` consumers for the eligible subset.
- It validates the Mechanic Factory path without pulling in battle, hidden, movement, lifecycle, or pending-interaction semantics.
- Blocked resource abilities should be skipped with named dependency reasons instead of blocking the core direct-action resource slice.

Scope limit:

- Include direct action mana, command seal, and VP mutations only.
- Exclude trigger-owned, battle-owned, hidden/private, movement-owned, cost-window, lifecycle-dependent, and result-binding hybrid resource abilities.
