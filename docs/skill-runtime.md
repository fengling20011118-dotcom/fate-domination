# 技能运行时约束

技能定义和技能效果处理器分离。`text` 只用于图鉴和预览，规则引擎不解析中文描述。

## 激活类型

- `passive`：满足条件时由规则事件强制触发，不生成玩家按钮。
- `phase`：在定义的阶段生成可选动作，必须经过统一合法性校验。
- `play`：作为牌或明确命令打出，使用卡牌实例和效果队列。

## 支持等级

- `FULL`：有确定的结构化处理器，可以进入普通对局。
- `PARTIAL`：仅完成部分规则，用于开发测试。
- `MANUAL`：没有自动处理器，必须禁止进入普通对局。

技能使用前统一检查：持有者、玩家状态、阶段、决策阻塞、使用次数和魔力费用。处理器只能通过 `SkillContext` 修改临时状态并开启可序列化决策，不能直接操作 UI 或旧版全局状态。
