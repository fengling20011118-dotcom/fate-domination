## 中文说明书（欧文）

圣杯战争桌游详细规则
翻译：欧文桑97 / b站专栏链接：https://www.bilibili.com/read/cv13738037
此说明书不是最新的，可能有少许错误，以QA为准
Fate/Domination（3-7名玩家）
在Fate/Domination中，你将扮演一名魔术师，在一场隐秘进行的，争夺圣杯的战争中战斗——据说圣杯也被称为万能的许愿机，能够满足获胜者的一切愿望。
为了战斗，你将召唤一位来自人类历史上的传奇英雄作为你的从者。
圣杯已经选出了七位御主。七名从者响应了你们的召唤。
圣杯战争在此展开。
如何赢得游戏
圣杯战争将持续11天（11个回合）。
每天晚上，玩家们都有机会与其他玩家竞争，以便在冬木市各处实现不同的目标，从而获得超越对手的优势。
他们在战斗中的胜利，以及其他增加其在圣杯战争中获胜机会的行动（如执行侦察），都将获取一定的胜利点数（战果）来衡量其优势。
在第8轮结束时，除战果排名前4的玩家外，所有人都被淘汰出局。
在第9轮结束时，除战果中排名前三的玩家外，所有人都被淘汰出局。
在第10轮结束时，除战果中排名前2的玩家外，所有人都被淘汰出局。
如果被淘汰的玩家之间有同分的，他们都不会被淘汰。
在第11轮结束时，战果最多的玩家获得圣杯并赢得比赛。
如果在游戏结束时多个玩家并列第一，那么在这一轮深山町战战斗中获胜的玩家将赢得游戏。
如果比赛仍以平局结束，圣杯将无法被获取，圣杯中的“泥”将溢出，所有人都将输掉比赛。
游戏版图的各个地点
冬木市分为4个位置，玩家可以前往：魔术工房、两个战场（深山町）和（新都）以及（侦察）。
（魔术工房）的玩家限制为4。（侦察）的玩家限制为1。
战场上的位置是无限的。如果您进入（深山町）或新都并且地利优势的格子被占用，请将您的御主放置在这些格子旁边。

游戏设置
1.决定起始玩家
用任意方式随机决定一名第一回合的起始玩家。起始玩家每回合结束都会更换。
2. 准备牌组
将所有事件卡洗混（B1），组成事件牌堆。
将10张非高潮回合的局势卡洗混，并且移除其中任意两张。将这8张卡洗混叠放在3张高潮局势卡上，组成一个11张的局势牌堆。（A1）
1-8回合：随机普通局势卡，面朝下放置
第9回合：停滞于命运之夜（4人高潮回合）
第10回合：身处地狱之门（3人高潮回合）
第11回合：天之杯（2人高潮回合）
3. 选择御主
让每个玩家选择自己想扮演的御主，亦或者大家统一决定用随机选择的方式。
拿出你的所有卡片与配件，向其他人解释你的能力。
将你的魔力设置在4点，这是你的初始魔力值。
如果玩家在4人以下，用没有加入游戏的御主的配件来加入一个npc。他在奇数回合开始时会部署在深山町的+3地利处，偶数回合开始时会部署在新都的+3地利处，并且会参与战斗，胜利也能得到战果。他的战力永远锁定为11，不会被其他效果修正，也不视为是一个玩家。战胜npc无法获得奖励战果（F）。
4.英灵召唤
用随机选择的方式抽取大家的从者。桌游模拟器的脚本默认的方式是，随机选择7个职阶的从者各一名，然后加入一名随机的额外职阶的从者，再从全英灵池里随机加入一名从者，制作一个从者池。现在玩家们从这9个从者里随机抽取从者。
你也可以定制你喜欢的方法，比如根据御主的强度决定能抽取从者的数量，只要大家都同意就可以。
每位玩家将自己的从者概览卡和三张技能卡面朝下放在桌子上，形成各自的技能区。将12张普通攻击卡洗混组成你的牌组。注意不要让别人看到你的从者的任何信息，这些都是保密的情报。
回合流程
每回合包括4个阶段：准备阶段、前哨阶段、行动阶段和战斗阶段。
每个阶段，玩家都按顺时针顺序轮流进行，从该回合的起始玩家开始，激活其卡面的特定阶段能力，并采取特定阶段的行动。
每个阶段，每个玩家都行动过后，继续下一阶段。在一轮结束时，当前起始玩家左边的玩家成为下一轮新的起始玩家。游戏就这样进行，直到第11轮结束，游戏结束。
技能激活限制和持续时间：除非另有说明，否则在卡片上的技能每轮只能激活一次，且效果持续到该轮结束。如果你拥有同一技能的多张相同的卡（例如，3张令咒卡），你可以为你拥有的每张卡激活一次技能。
1.准备阶段
所有玩家从他们的攻击牌堆中抽牌，将他们的手牌补充到3张。（已经有3张以上则不抽。）
抽取一张局势卡，将其放在激活中的局势卡区域（A2）。
所有玩家获得印在局势卡上的魔力值。
从事件牌组中抽出2张事件卡。
将其中一张面朝上放置在深山町（B2）中，另外一张面朝下放置在新都（B3）中。
接下来按照回合顺序，每个玩家可以激活有着【准备阶段】关键字的技能。
牌堆用尽：如果你必须从耗尽的牌堆中抽取牌，将其相应的弃牌堆洗混以形成新的牌堆。
2. 前哨阶段
玩家们按照回合顺序，在两个战场之一或【魔术工房】部署他们的御主立牌。
要注意，不能直接在【侦察】部署。
如果你在【魔术工房】中部署，你会立即获得在你部署的格子（C）上印有的魔力值，2点或者1点。
如果你部署在一个地利优势格子（D）上，只要你处于该格子上，你将在本回合战场上的战斗中，获得印在该格子上的地利优势。也就是会获得3点或者1点威力。
除非你是直接部署在这些格子上，不然你没法获得地利优势。
你移动离开，就会失去这些地利，移动进入一个战场，就放在地利优势旁边的任意地点。移动进入时不能获得任何地利。
在将你的御主部署到版图上之前或之后，你都可以激活有着【前哨阶段】关键字的技能。
3. 行动阶段
首先，将新都面朝下的事件卡翻面为面朝上。
然后，按照回合顺序，玩家都进行两步：先移动，然后攻击。
在你的回合中的任何时候，你都可以使用【行动阶段】关键字来激活技能。注意：只有当那张卡当前处于激活状态时，才能激活其上的技能。没有打出的攻击/技能卡，并不处于激活状态。
移动：你可以从一个地点移动到另一个地点，需要支付移动费用（E）数量的魔力值。
例如，从魔术工房到深山町需要1点，从深山町移动到新都需要2点。直接从魔术工房移动到新都则需要1+2=3点。
在此步骤中，你只能朝一个方向移动：从深山町到新都，从新都到侦查。
如果你正与其他人交战，那么你不能在此时进行移动。在两处战场有其他玩家或者npc的话，你就被视为交战中。不过，你可以移动到有其他人的战场。你可以经过其他人所在的战场，比如直接支付5魔力，从魔术工房移动到侦察。战场上的其他人并不会妨碍你。（使用急行之类的效果，可以无视交战时无法移动的限制。）
攻击：在本回合中，打出正好2张攻击卡，作为你的攻击组合。
这两张卡，可以是你手牌里的普通攻击卡，也可以是你技能区域的技能卡。要将技能区域中的牌作为攻击使用，你需要在攻击步骤开始时拥有8点或更多的魔力。
如果你的牌有魔力消耗，现在将他们一起支付。
（所以，你无法打出两张总耗魔量大于12点的卡，因为魔力是在同一时间支付的。）
在回合结束前，所打出的攻击/技能卡将变为激活的攻击，它们的能力现在可以被激活。
你可以将手牌面朝下打出，面朝下打出的牌没有消耗，也无法结算任何效果，回合结束就会弃掉。如果你在战场上，你只能面朝下打两张中的一张，如果不在战场上，可以都面朝下打出。
当你的攻击步骤结束时，计算并且告诉大家你总共的威力是多少。
【真名解放】
如果卡片上写有真名解放，那么打出这张卡的同时，你也要翻开你的概览卡，以及技能区的所有技能牌，给大家观看。
现在开始，你的真名就不是隐藏的了。
4. 战斗阶段
首先，按照回合顺序，玩家们轮流决定是否要使用【战斗阶段】关键字来激活技能。
然后，战斗开始了。计算每个玩家的总威力，将他们的攻击威力加上他们的地利优势，别忘了计算所有相关的修正。
分别确定每场战斗的胜利者，胜利者为各自战场上总力量最高的玩家。向每位获胜的玩家奖励其所在地所有激活事件卡的战果点数。
如果至少有一名其他对手（新版规则修改，玩家→对手）在胜利者所处的战场上，胜利者会额外获得该战场的奖励战果（F）。
如果两个或两个以上的玩家在一场战斗中都是威力最大的，则在他们之间平分该场战斗的战果（向上取整）。
最后，如果有玩家处于【侦察】，他可以获得2战果。
回合结束
回合结束时，丢弃所有激活的局势卡和事件卡。
玩家们各自收回自己的御主立牌。
关闭每位玩家激活的攻击卡，将他们打出的技能面朝上放回技能区，并将非技能攻击卡面朝下放到他们各自的弃牌堆中。你可以随时查看自己弃牌堆中的牌。
其他效果
【败北】
某些技能会造成一种称为【败北】的状态效果，持续到本回合结束。在战斗中确定胜利者时，忽略已经【败北】的对手，不管他们拥有多高的威力。
他们既不能获胜，也不能阻止其他玩家成为第一名而获胜。
此外，【败北】的玩家如果尚未打出卡牌，那么他们不能出牌。（已经打出牌的不受影响）
【一局游戏限一次】
如果使用了【一局游戏限一次】的卡，则其会在回合结束时从游戏中移除。
【残留】
带有【残留】关键字的卡牌，在被卡牌效果关闭之前，将保持在场上，回合结束阶段也不会关闭，并在以后的回合中处于激活状态。这代表之后每回合，残留的卡牌都会给你提供战力，你也可以激活残留卡上的效果。残留的卡牌在之后的回合，并不会占用你每回合两张牌的出牌限额。
【一局游戏限一次】的残留牌也会保持激活状态，直到它们被关闭，此时那张卡从游戏中移除。
【被动】
有着【被动：】的技能即使没有打出，也可以激活并使用。你只需要将其展示，然后就可以使用其效果。
【被动】效果是强制发动的，只要满足条件就会强制亮出展示，并且发动效果，而【被动/XX阶段：】的效果则是可选发动的，在其指定的阶段你可以选择是否发动效果。
另外，因为并没有打出被动效果的卡牌，所以即使魔力不满8点也是可以使用上面的效果的。
