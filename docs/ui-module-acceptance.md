# 首页、图鉴、自选与教程 UI 核验

核验日期：2026-10-01。

## 本轮范围

- 保留现有 7 名御主、7 名从者及原有视觉样式。
- 图鉴保留角色、局势、冬木事件三个分类；详情返回保留筛选与滚动位置。
- 自选点击角色原位更新；未选择时禁止确认；准备完成后返回可更换主从，保留已有选择。
- 设置和首页弹窗优先响应 Esc，避免关闭弹窗时直接离开所在页面。
- 新手教程提供六个章节、上一步/下一步和选择主从入口；这是操作说明教程，不是自动引导实战。
- 详细教程已改写为七章：开局与回合、地点与移动、出牌与情报、威力与结算、关键词、常见问题、3X 购点；五份原始文档保留为折叠参考。
- 教程数据由 `tools/build-tutorial-data.mjs` 从 `docs/tutorial-guide/` 和 `docs/rule-sources/` 生成，可运行 `npm run index:tutorial` 更新。

## 浏览器核验

使用 Edge、1280 × 720：

- 从声明页进入起始页、首页，再进入图鉴、教程、自选选择与阵容准备页。
- 检查角色图鉴数量、自选 Archer 筛选、选人节点保持、确认按钮状态、返回与更换主从。
- 事件图鉴滚动至 250 像素，打开可见卡片详情并返回，仍为 250 像素。
- 六个新手章节可逐页操作，五份详细文档可切换阅读。
- 阵容准备页六张角色/技能图片正常加载，浏览器无脚本错误。
- 检查教程与阵容准备页截图，修正教程章节栏继承角色详情布局造成首项过高的问题。

## 尚需单独处理

- 3X 模式当前只有七名御主；七位玩家各禁用一名且不可重复，会耗尽候选池。不能以重复禁用或额外静态角色绕过该问题。本轮没有修改其规则。
- 多人模式、存档恢复、未完成的技能定义与实战规则验证不属于本轮 UI 核验；不能据此声称整个游戏已完成。

## 事件规则纠正

- 基础规则要求每回合深山町明置一张事件、新都暗置一张事件，局势的「增加」在此基础上追加，不能代替基础抽取。
- 修正内容包的事件数量转换，并区分新都暗置基础事件与明置追加事件；浏览器运行包已重新构建。
- 13 张局势逐一验证数量、明暗、牌库扣除和无重复；与对局引擎现有测试一起，94 项通过。
- 浏览器验证自选进入对局、两地区基础事件展示、部署、移动、出牌、地区结算和进入下一回合，均通过。
