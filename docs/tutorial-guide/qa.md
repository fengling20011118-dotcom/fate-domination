# 威力怎样变成战果

先完成所有玩家的战斗阶段能力，再进行战力结算。不要仅凭某张牌的印刷威力判断最终胜者。

## 合计威力的计算顺序

1. 处理改变攻击基本威力的效果。
2. 处理增加、减少或改变攻击威力的效果。
3. 计算地利：先加成，再乘法，最后处理设置为特定数值的效果。
4. 将激活攻击的威力与地利相加。
5. 处理增加或减少合计威力的效果。
6. 最后处理将合计威力设置为特定数值的效果。

同一类效果通常按局势、事件、自己的能力、其他玩家能力的顺序处理；其他玩家能力按顺位结算。复杂卡牌组合可展开本章原文中的裁定查阅。

## 战场胜者获得什么

每处战场分别比较合计威力，最高者获胜。胜者获得该战场事件牌的战果；若至少有一名对手参战，再加上该地点的竞争战果。

例如，深山町事件奖励 3 点战果，你与对手交战并获胜，通常获得 3 + 2 = 5 点。若只有你一人，你仍可能获胜并取得事件奖励，但不能获得要求有对手参战的 2 点竞争战果。

并列最高时，可以有多名胜者。将事件奖励与竞争战果合计后平分，向上取整。以上例子的 5 点由两名胜者平分时，每人获得 3 点；特殊效果另有规定时按效果处理。

## 工坊与侦察也要查看

魔术工坊通常不进行战场胜负比较，但那里玩家的出牌、暗置牌数量及相关效果仍是回合信息。侦察玩家在战力结算时获得 2 点战果，抵达时不会立即获得。

界面按魔术工坊 → 深山町 → 新都 → 侦察 → 已展开的月之圣杯逐项展示。这个展示顺序不改变规则中视为同时获得的战果时点；暗置牌仍需遵守情报可见性。

## 回合结束要清理什么

先处理战斗结束后的效果，再移除地图上的御主，弃置本回合局势与事件。残留攻击按其规则保留，其他攻击关闭：技能牌明置返回技能区，非技能牌进入弃牌堆。限次牌按剩余次数处理，最后结算回合结束时效果。

## 高潮与最终胜负

第 8、9、10 回合结束时，分别保留战果前 4、3、2 名。淘汰线出现同分时，同分玩家均保留；避免淘汰的效果按其说明处理。

第 11 回合结束时，战果最多者获胜。若并列第一，比较本回合深山町的战斗胜者；仍无法决出胜者时，所有玩家都输掉游戏。

普通局势用于第 1—8 回合；第 9、10、11 回合依次使用「命运之夜」「身处地狱之门」「天之杯」。
