# 容易弄混的地方

## 我只有一个人在战场，也算获胜吗？

通常算，可以获得事件奖励及符合条件的胜利效果。但深山町 +2、新都 +3 的竞争战果要求有对手参战。若你被效果判定败北，也不能因为只有一人就自动获胜。

## 战场威力相同，会互相抵消吗？

不会。合计威力并列最高的玩家都可能成为胜者，并按规则平分战果、向上取整。

## 移动到空着的地利位，能得到地利吗？

通常不能。地利通过部署获得，而且结算时必须仍留在那里。常规移动到该地点不会自动补发地利。

## 到达侦察后就立刻加分吗？

不会。侦察的 2 点战果在战力结算时获得。如果此前离开，就不能按侦察位置取得这份奖励。

## 暗置牌一定没有效果吗？

不是。通常暗置牌不激活、不支付魔力、不计算威力，但它仍有印刷信息；符合条件的被动或明确处理暗置牌的效果仍可能影响它。对手不能因此随意查看隐藏内容。

## 技能牌没有打出，为什么被动仍可能生效？

被动与阶段能力的条件不同。被动可能无需激活牌；普通阶段能力通常要求激活。不能将「没打出」直接理解成「所有文字都无效」。

## 同时出两张牌，可以逐张付费吗？

不能。常规出牌同时支付两张牌的费用。通过其他效果后来额外打出的牌，才在对应时点另行支付。

## 攻击被关闭后，之前增加的威力还在吗？

依赖该攻击保持激活的威力效果通常也会失去作用。一次性的已结算效果与明确记载持续时间的效果，要按各自说明判断。

## 3X 买的淘汰加分能决定最后一天的冠军吗？

不能。购点只修正第 8、9、10 回合的淘汰判定，不加入实际战果，也不用于第 11 回合的最终胜负比较。
