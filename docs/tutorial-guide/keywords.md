# 看懂卡牌上的关键词

先看能力的时机，再看条件、费用和目标，最后执行效果。以下是经常影响操作的关键词。

## 被动

满足条件时必须执行，通常需要展示对应牌。被动不要求你先将牌作为攻击打出；隐藏的牌也可能具有需要处理的被动效果。

## 被动/某阶段

在标注的阶段可以选择使用。它不要求先激活对应牌，但阶段、条件、次数和其他限制仍然有效。

## 打出时

随打出动作处理的效果。「你可以」之后的部分可以选择是否执行，其余要求仍需遵守。

## 残留

攻击激活后可以跨回合保留，直到按效果被关闭。通常只在首次打出时支付出牌费用；若有维持费用或其他要求，按牌面执行。

## 唯一

多张牌具有相同的唯一能力时，不能因为持有多张就重复叠加或多次使用该能力。具体判断还需看它们的规则文本是否相同。

## 真名解放

发生真名解放时，展示从者概览及所有技能牌。隐藏真名的效果会使概览再次暗置；这不会自动等同于关闭你的攻击。

## 关闭攻击

攻击失去激活状态。技能牌明置返回技能区；其他明置攻击转为暗置，通常不会因这次关闭立刻进入弃牌堆。

## 败北 / 直接败北

通常持续到回合结束。被败北的玩家不能赢得战斗，也不能用自己的高威力阻止其他玩家获胜；确定胜者时忽略该玩家。

败北后不能再打出牌，但已有攻击不会自动取消，也不等于禁止使用所有能力。具体卡牌另有说明时按其效果处理。

## 阶段能力的次数与持续时间

除非另有说明，同一张牌上的阶段能力每回合通常只能使用一次，效果持续到本回合结束。先确认能力是否已用过，再判断是否满足费用与目标。
