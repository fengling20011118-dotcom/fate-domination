# 地点决定你的收益

每回合部署前，先看本回合的局势、战场事件和空余位置，再决定要补充魔力还是争夺战果。

## 四个常规地点

| 地点 | 人数与部署 | 主要作用 |
| --- | --- | --- |
| 魔术工坊 | 通常最多 4 人，可直接部署 | 部署时立即获得工坊位标注的魔力 |
| 深山町 | 战场，人数不限，可直接部署 | 争夺事件奖励；有对手参战并获胜时另得 2 点竞争战果 |
| 新都 | 战场，人数不限，可直接部署 | 争夺事件奖励；有对手参战并获胜时另得 3 点竞争战果 |
| 侦察 | 通常最多 1 人，不可直接部署 | 战力结算时获得 2 点战果 |

月之圣杯属于由相关效果展开的特殊区域，进入条件和奖励遵循对应能力说明，不能直接套用常规地点的全部规则。

## 怎样部署

轮到你时，在地图上选择合法地点。工坊位和战场地利位按标注数字从高到低占用；没有空余地利位时，仍可以部署到战场的普通位置。

工坊位的魔力立即获得。战场地利则在战力结算时加入合计威力，前提是你通过部署获得了这个位置，而且结算时仍留在那里。

例如，你部署在深山町的 +3 地利位，之后没有离开，结算时获得对应地利。若你后来从别处移动到深山町，即使那里空着 +3 地利位，也不会因此获得部署地利。

## 怎样常规移动

在自己的行动阶段，先点击「常规移动」，再选择合法目的地。常规移动发生在常规出牌之前，需要支付沿途移动成本。

移动方向固定为：魔术工坊 → 深山町 → 新都 → 侦察。

成本按离开或经过的地点累计。按照基础地图，从工坊移动到侦察需支付 2 + 2 + 1 = 5 点魔力；卡牌能力可能改变费用或移动方式。

## 为什么有时不能移动

处于交战状态时，不能常规移动：你与至少一名对手一起位于会发生战斗的战场，就算交战。

目的地没有可用名额，或魔力不足以支付费用，也会限制移动。沿途经过已发生交战的战场，不会单独阻止你通过；经过与停留是两回事。

令咒或卡牌造成的移动按其效果处理，不能直接当作常规移动判断。
