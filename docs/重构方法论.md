# 技能结构化重构方法论（子代理必读）

## 目标
把 `supportLevel: PARTIAL` 的技能重构为 `FULL`，通过给技能配置 `core.structured-skill` handler + 完整 `rules.abilities[]`。

## 核心判定链路（已验证）
`src/content/skill-package.ts` line 96:
```
supportLevel: confirmed?.supportLevel ?? parsedSupport ?? toSupportLevel(skill.implementation)
```
→ 只要在 `structured-batch-XXX.ts` 里给技能写 `supportLevel: "FULL"` + `handlerId: "core.structured-skill"` + 完整 `rules`，audit 就判 FULL。

## 写法模板（对照 src/content/structured-servant-batch.ts 已有 10 个范本）
```ts
"servant.xxx.skill.sc-xxx-1": {
  activation: "phase", windows: ["action"], steps: ["player-window"],
  requiresTrueName: true, revealsTrueNameOnPlay: true,  // 有【真名解放】时
  handlerId: "core.structured-skill", supportLevel: "FULL",
  rules: {
    schemaVersion: "fd-card-authoring-v1",
    abilities: [
      {
        id: "xxx", kind: "phase_action", activation: { phase: "action" },
        printedClause: "行动阶段：...（原文字面）",
        execution: { mode: "automatic" },
        conditions: [{ type: "source_active" }],
        effects: [{ type: "gain_mana", amount: 2 }],
      },
    ],
  },
},
```

## 可用的 effect（executeStructuredEffects 里的 case，均支持 snake_case 和 kebab-case）
- draw_cards / draw-cards：抽牌 { amount }
- gain_mana / gain-mana：得魔力 { amount }
- gain_victory_points / gain-victory-points：得战果 { amount }
- lose_victory_points / lose-victory-points：失战果 { amount }
- discard_all_hand / discard-all-hand：弃所有手牌
- combat_power_bonus / combat-power-bonus：合计威力 { amount }（支持负数）
- source_card_power_bonus / source-card-power-bonus：本牌威力 { amount, duration }
- defeat_player / defeat-player：令目标玩家败北
- move_forward：沿箭头移动一步 { steps }
- move_player：移动玩家到指定地点 { target:"controller", locationId }
- hide_true_name / reveal_true_name：隐藏/揭示真名
- close_owned_active_cards_by_definition：关闭牌 { definitionId:"self", count }
- choose_cards：选牌（复杂，谨慎使用）
- choose_one：选一项
- if_condition：条件分支
- set_player_flag / clear_player_flag / increment_player_flag：旗标
- add_player_flag_number：旗标数值
- pay_mana：支付魔力

## 可用的 condition（assertStructuredConditions 里的 case）
- source_active：本牌激活
- event_type_is：事件类型 { eventType }
- event_player_is_controller：事件玩家是控制者
- event_definition_is_self：事件牌是自己
- event_face_is：牌面 { face }
- event_player_won_combat / event_player_lost_combat：赢/输战斗
- phase_is：阶段 { phase }
- location_is / location_in：位置
- at_battlefield：在战场
- player_flag_equals：旗标等于 { key, value }
- player_flag_number_at_least：旗标数值至少
- true_name_hidden / true_name_revealed：真名状态
- target_count_at_least / target_count_equals：目标数

## 铁律（来自 structured-batch-002.ts 注释，必须遵守）
1. **仅在整张卡的语义都能被结构化效果或既有通用字段精确表达时才登记 FULL。**
2. **任何无法精确表达的条款都不得登记，保持 host_adjudicated 状态。**
3. 不得臆造规则。语义不确定的一律不写 FULL。
4. 真名解放用 `revealsTrueNameOnPlay: true` 字段表达，不写进 abilities。
