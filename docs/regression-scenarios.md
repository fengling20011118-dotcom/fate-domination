# 玩家反馈回归场景

下列场景来自旧版真实反馈。相关模块迁移完成前必须建立自动测试，不能仅靠手动点击确认。

## 阶段与被动

- 强制 `被动` 在满足条件时自动进入效果队列，不显示为普通主动按钮。
- `被动/XX阶段` 只在拥有者自己的对应阶段提供可选操作。
- 一张牌上的行动阶段能力与前哨阶段分能力必须分别判断，不能因其中一个窗口合法而执行另一个效果。
- 取消可选能力后，阶段队列继续推进，不出现界面跳阶段但无法操作的死档。
- 非本人御主或从者的专属技能不得出现在自己的操作提示中。
- 玩家进入【败北】状态后，本回合不能再打出任何牌；其此前已经打出的牌不会被取消。
- 能够无视【败北】的效果只改变对应规则允许的部分，不能让普通出牌流程绕过出牌锁定。

## 基础回合与结算

- 开局将10张非高潮局势牌洗牌，由确定性随机数抽取2张暗置移出游戏；剩余8张构成普通局势流程。
- 被移除的2张非高潮局势牌不会在本局通过普通抽取重新出现。
- 高潮局势牌不参与上述10选2流程，并按高潮回合规则进入游戏。
- 侦察地点的玩家在规定的战果结算时点获得2点战果，不能重复结算、漏结算或错误依赖战场胜负。
- 侦察战果与深山町、新都的战斗战果在同一轮结算流程中只处理一次。

## 已知角色场景

- 提亚马特【生命之海】可在行动阶段作为攻击使用；“前哨阶段：关闭此牌……”只在前哨阶段发动。
- 【生命之海】加入的三张魔兽必须进入可见区域，并能在获得它们的当回合行动阶段打出。
- 莱妮丝【炼金术师】由玩家选择一张【特里姆玛乌】，不能随机获得。
- 佩佩隆奇诺的时代、印度事件与持续状态必须自动建立、推进并可视化。
- 宫本武藏【境界】仅在真名解放后对其他玩家显示。
- 杀生院祈荒的秘密花园持有者可以查看自己的秘密花园卡图。
- 天草四郎【神仆】双方状态与公开标志一致。
- 巴泽特的时间进程可以通过公开状态查看。
- 阿蒂拉【军神之剑·泪之星】放置后必须出现在对应地点，并使用文明废墟专用事件池。
- 远野志贵【退魔者】取消选择不会阻塞开始能力或阶段流程。
- 狄俄斯库里【凡性之赠】按明确阶段窗口正常使用。
- 三藏法师【金蝉子】弃置幸运后的三个选项都必须产生对应效果。
- 弓兵卫宫及其他名为【无限剑制】的牌按特殊属性处理，不因宝具禁止而无法使用。
- 普通令咒效果不得直接触发真名解放。

## 事件交互

- 事件进入场地、揭示、移除、替换和洗回牌堆均由规则事件驱动。
- 【神之遗产】相关事件按条件自动发放；结算后应移除并补充新事件。
- 每局仅选择一个普通事件组；冬木组固定为 20 张。
- 文明废墟不进入普通事件组轮换。
- 玩家必须能对需要选择对象、地点、牌或数量的事件作出明确选择。

## 3X 与联机

- 新房间拥有新的 `gameInstanceId`，不会加载上一房间的禁用、选人或游戏状态。
- 连续点击加入不会创建空玩家或重复玩家。
- 准备、禁用、选人和确认命令均为幂等操作，一次点击即可生效。
- 所有客户端显示相同的已准备人数。
- AI 禁用先由房主结算并广播，真人选择前能够看到禁用结果。
- 无论房主或客机谁先准备，所有人都只能在同一修订号进入游戏。
- 阶段、当前行动玩家、出牌、选择和战斗结算均由房主权威状态驱动。
- 客户端重连后恢复当前快照及未完成选择，不恢复旧房间快照。
