# 重构版 UI 约束

## 地图

- 保留旧版 3×2 版图结构：左列依次为局势牌堆、事件牌堆、侦察；右列依次为魔术工房、深山町、新都。
- 保留原地点卡图、地名、地利槽、移动方向、事件摆放区和玩家标记语义。
- 地图通过独立 `MapView` 渲染，只接收视图模型和点击回调。
- 地图不读取全局 `State`，不调用规则引擎内部函数，也不直接修改玩家位置。

## 其他界面

- 开始页、模式流程、3X 禁用选人、玩家面板、技能区、手牌区、阶段操作、操作记录和弹窗重新编写 DOM 结构。
- UI 只根据 `getLegalActions()` 生成可操作控件。
- 卡图和技能描述来自内容仓库，状态标志来自公开视图模型。
- 未公开真名对应的信息必须经过可见性过滤后才能传给其他客户端。
- 七人局仍需保持地图、对手信息和当前出牌可读，不使用缩小到无法辨认的整体缩放。
